# Login Transparent

Tela de login transparente desenvolvida como estudo de HTML, CSS e JavaScript.

O projeto apresenta uma interface de autenticação com efeito visual de transparência, imagem de fundo, formulário centralizado, ícones nos campos e elementos como "Remember me", "Forgot password" e link de cadastro.

## Sobre o projeto

O **LoginTransparent** é uma página estática criada para praticar construção de interfaces modernas com HTML e CSS.

A tela utiliza uma imagem de fundo e aplica um efeito de vidro no formulário por meio de transparência, bordas suaves, sombra e `backdrop-filter`. Também há um pequeno script JavaScript associado ao botão de login.

## Funcionalidades visuais

- Formulário centralizado na tela;
- Campo de usuário;
- Campo de senha;
- Opção "Remember me";
- Link "Forgot password";
- Botão de login;
- Link para registro;
- Imagem de fundo;
- Responsividade;
- Efeito transparente no card;
- Ícones nos campos do formulário.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- Google Fonts;
- Ícones externos;
- Efeito `backdrop-filter`.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/thamiscoder/LoginTransparent.git
```

2. Acesse a pasta do projeto:

```bash
cd LoginTransparent
```

3. Abra o arquivo `index.html` no navegador.

Também é possível usar a extensão **Live Server** no VS Code.

## O que foi praticado

- Estruturação de formulário com HTML;
- Estilização de tela de login com CSS;
- Centralização com Flexbox;
- Uso de imagem de fundo;
- Aplicação de transparência e blur;
- Uso de bordas arredondadas e sombras;
- Estilização de inputs;
- Criação de layout visual moderno;
- Primeiros testes com JavaScript em formulário.

## Observação

Este projeto é visual e voltado para estudo de interface. Ele não possui autenticação real, banco de dados ou validação segura de login.

## Objetivo de estudo

O objetivo do projeto é praticar a criação de uma tela de login estilizada e entender melhor como HTML, CSS e JavaScript podem ser usados juntos em uma interface simples.
